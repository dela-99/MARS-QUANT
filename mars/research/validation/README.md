# Validation Reports
 
Store human-readable validation summaries here.
 
Machine metrics also go to `experiment_logs/` via `mars.research.ExperimentLog`.
 
Minimum validation pack for any accepted hypothesis:
 
- Sharpe / Sortino / Calmar / Max Drawdown
- Bootstrap confidence intervals
- Information Coefficient
- Purged Cross-Validation
- Walk-Forward Validation
- Out-of-sample holdout
- Feature importance + stability
